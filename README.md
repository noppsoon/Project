# Employee Attriotion Prediction Using Machine Learning
Predicting employee attrition using machine learning and ststistical analysis to identify key factors associated with employee turnover and support data-driven HR decision-making

## Project Overview
Employee attrition can increase recruitment costs, reduce productivity, and disrupt business operations. This project anlyses employee characteristics and workplace factors to identify patterns associated with attrition and develops predictive models to identify employees at higher risk of leaving.
The project follows a complete end-to-end machine learning workflow, including data understanding, data preparation, exploratory data analysis, statistical testing, predictive modelling, model evaluation, threshold optimisation, and business interpretation.
