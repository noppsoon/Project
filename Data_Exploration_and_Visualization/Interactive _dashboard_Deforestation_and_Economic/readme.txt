
# The Economic and Environmental Impacts of Deforestation

An interactive dashboard exploring forest-related environmental and economic indicators across countries, regions, and income groups from **2000 to 2020**.

## Project Objective
Explore changes over time, geographical differences, and relationships between forest area, CO₂ emissions from deforestation, agriculture-related GDP share, and temperature anomalies.

## Dashboard Pages
- **Tutorial:** Instructions for navigating the dashboard and using its interactive features.
- **Feature Trends Over Time:** Line charts showing global trends and comparisons by region or income group, with selectable indicators and year ranges.
- **Global Overview:** A choropleth map, global average trend, and top 10 ranking chart for the selected indicator.
- **Variable Relationship Explorer:** Scatter and bubble plots with selectable axes, an optional bubble size variable, and filters for year, region, and income group.

## Interactive Features
- Adjust years using sliders.
- Select indicators and grouping options using dropdowns.
- Hover over visualisations to view details.
- Explore geographical patterns and relationships between indicators.

## Interpretation
The dashboard supports exploratory analysis. Relationships shown in the charts do not establish that deforestation causes changes in other indicators.
